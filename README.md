# WorkBuddy 小白场景手册（v2）

面向**零基础小白**的 WorkBuddy 实用场景手册，不是教程、是手册。

22 篇短文，每篇解决一个具体问题，给一段能直接抄的 Prompt。
每篇 3 分钟读完，读完就能用——翻到哪篇看哪篇，不用按顺序读。

> 配套还有一套更系统的《WorkBuddy 进阶指南》（面向已用过、想系统掌握的人），本仓库仅收录入门手册 v2 全套。

---

## 怎么读

- **在线读（推荐）**：打开 `WorkBuddy能干什么-小白场景手册-全本.html`，自带左侧目录、手机抽屉菜单、51 个 Prompt 一键复制。
- **看源码**：`WorkBuddy能干什么-小白场景手册-全本.md` 是纯文本正文，可任意复制改编。
- **发朋友圈**：`朋友圈海报.png` 是分享用海报（扫码即看）。
- 本仓库 `deploy/index.html` 与上面那本 HTML 内容一致，可直接部署到任意静态托管。

## 全书结构（22 篇 / 8 组）

| 分组 | 篇目 |
|------|------|
| ① 上手试试 | 1 提醒小助手 · 2 清理电脑存储 · 3 帮你查资料 · 4 帮你翻译 |
| ② 帮你写 | 5 写周报/月报 · 6 写邮件 · 7 读 PDF |
| ③ 帮你算 | 8 排班表/清单 · 9 分析 Excel · 10 做图表 |
| ④ 帮你做 | 11 做 PPT · 12 做配图 · 13 做短视频 |
| ⑤ 帮你造 | 14 搭个人网站 · 15 做小工具 |
| ⑥ 帮你盯 | 16 每日工作简报 · 17 整理文件夹 |
| ⑦ 帮你连 | 18 连邮箱 · 19 连网盘 |
| ⑧ 进阶一点 | 20 装技能 · 21 找专家 · 22 综合实战 |

附录：A 提问万能句式 · B 翻车急救手册 · C 术语大白话对照。

## 本地重新生成 HTML

```bash
# 需要 python markdown 库
pip install markdown
python _convert.py
```

脚本会读取 `WorkBuddy能干什么-小白场景手册-全本.md`，输出 `WorkBuddy能干什么-小白场景手册-全本.html`。
